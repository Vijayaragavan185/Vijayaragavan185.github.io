AnaemiaScreen

02

Exploring anaemia screening from eye images, with careful model evaluation and a Java Android app that works offline.

  • PyTorch
  • OpenCV
  • Java
  • LiteRT
Inside the research +

A three-seed MobileNetV2 ensemble reached 0.881 pooled out-of-fold AUC (95% CI: 0.860–0.903). A separate precision study reduced a classifier from 8.57 MB to 2.54 MB while retaining 0.866 AUC. Cross-dataset transfer remains limited; this is a screening research prototype, not a diagnostic product.

RoadSense Research

03

Detecting potholes through road vibration, using dual sensors and a temporal convolutional network with attention.

  • TensorFlow Lite
  • Python
  • C
  • ESP32
Inside the research +

The full model achieved 96.7% test accuracy on a study using 3,245 labeled signal windows. Distillation, pruning and quantization produced a 342 KB edge model with 95.8% accuracy and 47 ms inference. The accuracy and latency figures describe different model variants.
