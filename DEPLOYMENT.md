This repository hosts the static portfolio on GitHub Pages, using the root of the `main` branch. Hosting and the `github.io` address are free for this public repository; no purchased domain is required.

## Validation

Before publishing: JavaScript syntax and local image, stylesheet, script, PDF and anchor references checked. The same site was visually checked at mobile and desktop sizes, with functioning project disclosures and email-copy feedback.

After pushing: verify the Pages build for the published commit and request the public URL without authentication.

## Updating

Copy only the site's deployable files into this repository. Preserve `.git`, this deployment record and README. Commit each logical change with a descriptive subject and a body covering its purpose and validation, then push `main`. GitHub Pages redeploys automatically.

The displayed anime artwork is an AI-generated interpretation of the owner's supplied photo. Research metrics retain their evaluation context; the anaemia project is a research prototype, not a diagnostic product.
